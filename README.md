## 📌 Project Overviews

### 01. [Weather ETL Pipeline](./weather-etl-pipeline)
- **Description:** An automated end-to-end data pipeline fetching real-time weather metrics, persisting raw JSON backups, and loading structured, timestamped logs into a relational MySQL database.
- **Key Takeaways:** Schema design, secure environment variables (`.env`), API error handling, and robust ETL flow.

### 02. [FinTech Market Pipeline](./fintech-market-pipeline) *(Completed)*
- **Description:** A scheduled ETL pipeline that fetches Bitcoin and Ethereum prices, 24-hour volume, and price changes from CoinGecko, stores timestamped snapshots in MySQL, and generates price-trend charts.
- **Key Takeaways:** REST API ingestion, JSON processing, MySQL schema and snapshot storage, Pandas summaries, Matplotlib visualization, and scheduled execution.
