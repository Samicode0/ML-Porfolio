## Project Overviews

### 01. Weather ETL Pipeline
Automated data pipeline fetching real-time weather metrics from Open-Meteo API, storing raw JSON backups, and loading structured logs into MySQL.

### 02. FinTech Market Pipeline
Scheduled ETL pipeline tracking crypto prices via CoinGecko API, storing timestamped snapshots in MySQL, and generating trend charts.

### 03. Credit Risk Scoring Engine
Machine learning pipeline predicting loan default risk using XGBoost on 268k loan records. Features automated data cleaning, risk threshold tuning, and an interactive Streamlit dashboard for real-time loan decisions.
