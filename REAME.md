### 01. [Weather ETL Pipeline](./weather-etl-pipeline)
- **Description:** An automated end-to-end data pipeline fetching real-time weather metrics, persisting raw JSON backups, and loading structured, timestamped logs into a relational MySQL database.

### 02. [FinTech Market Pipeline](./fintech-market-pipeline) *(In Progress)*
- **Description:** Automated crypto/stock pipeline fetching real-time market data, calculating moving averages and price velocity using Pandas, and auto-generating trend analytics charts.
- **Key Takeaways:** Handling `DECIMAL` precision for financial values, multi-asset comparative analysis, and automated scheduling.
